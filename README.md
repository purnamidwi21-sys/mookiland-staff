# Mookiland Staff

Form input untuk barista (bar stock) dan kasir (cash count). Data tersimpan ke Google Sheet **Daily Report** lewat Apps Script.

- Barista: https://purnamidwi21-sys.github.io/mookiland-staff/?role=barista
- Kasir: https://purnamidwi21-sys.github.io/mookiland-staff/?role=cashier

`config.js` berisi link web app Apps Script (`/exec`). Halaman ini dibuat dari `src/App.html` di repo `daily-report-apps-script` dengan `tools/build_pages.py`.
